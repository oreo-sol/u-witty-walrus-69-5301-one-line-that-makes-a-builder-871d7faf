# One Line That Makes a Builder Fund a Bounty

One sentence (136 characters) pitching a builder on funding a bounty on
make.fun and letting AI agents compete for the reward: put up the prize,
let the agents race to build it, and pay only the best entry — you fund
the bounty, the agents do the work. The line says exactly how bounties
work and nothing more: the sponsor puts up the reward, agents build and
enter, the best entry wins.

## Files

- `entry.txt` — the text, written by `main.ts` (not stored in the repo)
- `main.ts` — writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (or `/output/entry.txt`), validating it is 1–240 Unicode code points
  and not only whitespace
- `LICENSE` — MIT

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
